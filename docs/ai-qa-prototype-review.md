# AI 智能问答平台｜原型需求审查

**当前原型已补齐首轮报告指出的多项展示和模拟交互。** AC01–AC07 的业务验收仍以实际系统行为与测试证据为准。各项源码复核见第 4 节，视觉差异和实施状态分别见[前端偏离报告](./ai-qa-frontend-deviation-report.md)和[实施状态](./ai-qa-status.md)。

## 首轮审查记录

首轮结论是主要页面和多数业务状态已有设计表达，但当时撤回后内容仍可读、无权限空间名仍可见，发布审核链、空间搜索和文档引用也不能按需求走完。第 1–3 节保留当时的发现、验收条件和建议。行号链接指向当前文件，内容已随原型演进。

- 需求基线为 [PRD v0.5](./ai-qa-prd.md#L25)及[首期技术方案](./ai-qa-technical-design.md)。
- 首轮审查了工作台及其余 8 个 HTML 页面和共享样式。审查逐页静态对照，并在隔离 Chrome 打开工作台、知识库、导入、发布、助手、统计页面核对可见状态和入口。首轮原型未接后端。

## 3. 已覆盖的状态与首轮验收边界

| 用例 | 当前证据及结论 |
| --- | --- |
| AC01、AC02 | [导入](../原型图/import.html#L87)提供成功、同名跳过、扫描件无正文、失败原因和重试的设计样例。重试按钮无真实处理，无法验证并发去重、失败恢复与索引更新；版本文件名存在 B01 偏差。 |
| AC03、AC04 | [回答模板](../原型图/answer-templates.html#L44)正确表达助手优先、全局兜底；[助手](../原型图/assistant.html#L129)有无依据、失效和冲突的设计样例。权限、文档定位及个别回答结论尚不符合需求。 |
| AC05 | [发布管理](../原型图/publish.html#L71)描述了重审期间未审变更不外露，但浏览器无法通过现有交互完整走完审核与重提。 |
| AC06 | 有撤回历史样例，但已撤回正文仍实际可读，原型层不通过。未执行后端撤回与继续追问验收。 |
| AC07 | [统计](../原型图/stats.html#L40)声明北京时间、跨空间只计一次、重试去重和 Tokens 未上报不记零；周期切换和用户级对账未达验收。 |

**首轮建议的修复顺序为 A01–A03、B01–B04、B05。** 前端沿用视觉基线，业务行为按需求和接口契约实现。

## 4. 当前原型与实现复核

当前审查对象包括 [工作台](../原型图/workbench.html)、[文档详情](../原型图/document.html) 及其余 8 个 HTML 页面。原型的发布状态在同源页面通过 `localStorage` 共享，搜索、问答及统计使用演示数据。以下为源码对照，测试链接指向仓库已有测试，本节未重跑业务验收。
