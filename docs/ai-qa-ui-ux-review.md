# AI 智能问答平台 · 前端视觉与交互验收报告

评审日期 2026-11-23。综合 UI 视觉验收设计师、UI 设计师和产品经理的评审意见，以当前前端、配套后端和原型为依据。桌面正文铺满、两侧各留 20px 沿用已确认的设计。

优先处理四类问题：窄屏上无法顺畅搜索或退出，助手会话与可用资料范围容易被误读，审核后缺少清晰的恢复和撤回路径，以及维护者无法在页面修改草稿后重提。

## 浏览器实测

本地 Chromium 使用开发身份进入工作台。测量值为 CSS 像素，输入宽度包含边框和内边距。此处只记录实际观察到的页面行为。

| 页面与条件 | 实测结果 | 对应问题 |
| --- | --- | --- |
| 工作台，390 × 844 | 空间下拉占 180px，关键词输入仅 58px，搜索按钮占 62px。账号区不可见 | V01、V02 |
| 工作台，320 × 800 | 关键词输入仅 26px，页面内容宽 342px，超出视口 22px。账号区不可见 | V01、V02 |
| 工作台，已登录 | 最近会话显示「会话」加 ID 前缀，单条记录没有直达链接。创建空间入口指向知识库 | U10 |
| 登录页，1440 × 900 | 可见用户名、密码及仅用于本地开发的折叠入口。企业 SSO 入口未出现 | 登录范围符合当前交付约定 |

其他条目由源码或原型对照确认。中文输入法、真实模型回答、不同角色的业务流程及破坏性操作列入后续动态验收。

## P1 · 优先处理

| 编号 | 问题与影响 | 可验收的修复结果 |
| --- | --- | --- |
| V01 | **窄屏工作台搜索难用。** 固定宽度选择器和不换行的布局挤压输入框，320px 出现水平溢出。 [工作台搜索样式](../frontend/src/views/WorkbenchView.vue#L725) | 320px、390px 均可完整编辑「差旅报销」，空间下拉和搜索按钮都可操作，页面无水平滚动。 |
| V02 | **窄屏丢失账号与退出入口。** ≤860px 隐藏侧栏底部的账号区和退出按钮。 [账号与退出](../frontend/src/layouts/AppLayout.vue#L82) · [断点](../frontend/src/layouts/AppLayout.vue#L405) | 在 390px、860px、861px 都能用鼠标和键盘访问账号与退出。取消确认保持会话，确认后返回登录页。 |
| V03 | **弹窗的键盘行为不统一。** 创建空间、模板和删除会话等弹窗缺少一致的焦点管理。删除还使用普通主按钮，失败后关闭弹窗。 [共享弹窗](../frontend/src/components/ModalShell.vue#L14) · [创建空间](../frontend/src/views/KnowledgeView.vue#L417) · [模板弹窗](../frontend/src/views/AnswerTemplatesView.vue#L342) · [删除会话](../frontend/src/views/AssistantView.vue#L788) | 打开后焦点进入弹窗，Tab 与 Shift+Tab 在窗内循环，Esc 关闭后还焦。删除确认默认聚焦取消，使用现有危险按钮样式，失败留在弹窗内提供重试。 |
| U01 | **助手标示的可用范围可能大于真实取证范围。** 显示逻辑只取绑定和可见空间的交集，而后台管理列表也可能包含未发布或仅可维护的空间。助手把这些空间标成「有权限」。 [助手范围](../frontend/src/views/AssistantView.vue#L134) · [实际取证](../backend/src/main/java/dev/aiqa/answer/AnswerService.java#L128) | 只把已绑定、可读且已发布的空间展示为可用。无助手、无授权空间、读取失败各有清楚的提示。测试只读已发布、仅维护和已撤回三类空间。 |
| U02 | **切换会话会把未发送草稿带到另一会话。** 输入框内容独立于会话 ID，发送时使用当前会话。 [草稿状态](../frontend/src/views/AssistantView.vue#L71) · [发送](../frontend/src/views/AssistantView.vue#L382) | 在 A 写草稿后切到 B，B 不显示也不发送 A 的内容。切回 A 恢复原草稿。新会话和发送失败后也能保留各自草稿。 |
| U03 | **中文输入法确认候选词可能触发提问。** Enter 直接进入提交逻辑，未判断组合输入。 [助手输入框](../frontend/src/views/AssistantView.vue#L762) | 使用中文输入法时，回车确认候选词只完成上屏。普通 Enter 发送，Shift+Enter 换行。至少覆盖 Chromium 和 Safari 的真实输入法操作。 |
| U04 | **草稿页面缺少驳回后修改的入口。** 导入加入草稿时默认标为现行，知识库草稿提供预览和提交，未提供政策状态、日期或条目调整。 [导入加入草稿](../frontend/src/views/ImportView.vue#L339) · [草稿列表](../frontend/src/views/KnowledgeView.vue#L628) | 驳回后能查看原因，修改有效性和日期，移除误选条目并重提。待审期间，读者继续访问上一个已审版本。 |
| U05 | **发布等待索引时缺少故障反馈和恢复路径。** 解析失败会阻塞生效，详情中看不到已有的逐文档解析状态，提示仍是索引完成后自动生效。 [页面提示](../frontend/src/views/PublishingView.vue#L191) · [就绪判断](../backend/src/main/java/dev/aiqa/publish/PublishRepository.java#L240) | 审核后让一项解析进入失败，详情显示阻塞文件、状态及下一步。重试成功后更新生效状态，恢复前保留旧版本。 |
| U06 | **撤回容易误判操作对象。** 在历史申请详情中，按钮仍可作用于空间的当前发布版本。页面复用审核意见且缺少独立确认，历史申请仍可能显示「已发布」。 [撤回操作](../frontend/src/views/PublishingView.vue#L206) · [申请详情](../frontend/src/views/PublishingView.vue#L429) | 按 A → B → 撤回测试。撤回前明确告知当前版本 B、独立原因和影响。取消不会改变发布状态。撤回后可区分已替代、已撤回和已作废。 |
| U07 | **不同入口对回答有效性的呈现不一致。** 工作台快捷问答的正文缺少助手页面已有的无依据、已失效、待核实和冲突标记。 [工作台回答](../frontend/src/views/WorkbenchView.vue#L584) · [助手回答](../frontend/src/views/AssistantView.vue#L678) | 同一组回答状态在两处使用相同的提示和引用规则，政策状态在阅读正文前即可识别。 |

## 产品验收依赖

- **回答证据与撤回。** 当前一次模型回答整段存储，依赖本次提供的全部候选。若一个答案里含 A、B 两段独立结论，撤回 B 可能连同 A 一起屏蔽。验收用两个独立来源生成回答，核对未受影响段落可保留，撤回段落与引用不可见。 [段落证据写入](../backend/src/main/java/dev/aiqa/answer/AnswerService.java#L245) · [历史过滤](../backend/src/main/java/dev/aiqa/api/QaController.java#L528)
- **无依据与政策冲突。** 网关未解析出有效编号时会把候选全量当作引用，冲突标记主要依靠同名多版本，难覆盖改名后入库的冲突政策。使用有标准答案的样本验证无依据回复不附误导引用，冲突回复能列出差异及对应来源。 [引用解析](../backend/src/main/java/dev/aiqa/answer/GatewayAnswerModel.java#L85) · [冲突规则](../backend/src/main/java/dev/aiqa/answer/AnswerService.java#L268) · [需求基线](./ai-qa-prd.md)
- **发布详情形态。** 原型采用右侧抽屉，实现采用居中对话框。是否改回抽屉由产品确认。两种形态都需验证长清单滚动、关键操作可达、取消后保留列表筛选。 [发布原型](../原型图/publish.html#L84) · [发布详情](../frontend/src/views/PublishingView.vue#L340)

## 建议验收顺序

1. 在 320px、390px、860px、861px 和 1440px 验证布局与账户入口。用键盘走一遍创建、取消和删除确认。
2. 以只读用户、空间维护者和系统管理员核对助手范围、创建与导入入口。用中文输入法与两个会话验证提问行为。
3. 使用隔离数据走完整的导入、解析失败、修复、驳回重提、发布、切版和撤回流程。
4. 用有明确出处的政策样本验收引用、无依据与政策冲突，再用跨日及 201 条以上的提问记录核对统计。
