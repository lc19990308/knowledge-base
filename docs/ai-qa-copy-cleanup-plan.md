# 前端「AI 味」提示文案清理方案

> 状态：**A 档已执行**（2026-11-24）· 范围：`frontend/src` 的界面提示文案 · 不涉及后端、不改交互逻辑
> 执行结果见文末「八、执行记录」。

## 一、判定标准：什么叫「AI 味」

本方案把提示文案分成四类。前四类是「AI 味」，最后一类不删。

| 类型 | 特征 | 例子 |
| --- | --- | --- |
| T1 规则搬运 | 把需求文档 / 验收条件原样贴到界面上 | 「模板不得覆盖权限、引用和政策有效性规则」 |
| T2 口径解释 | 解释统计怎么算、指标怎么定义 | 「按北京时间分桶，只统计提问与失败」 |
| T3 实现暴露 | 讲后端机制、密钥、错误码、占位模型 | 「提交会返回 403」「服务端密钥管理解析」 |
| T4 爹味说教 | 教育用户权限模型与注意事项，不指导下一步操作 | 「维护权限不等于发布权限：…仅系统管理员可执行」 |
| **保留** | 操作指引、校验反馈、状态反馈、无障碍标签 | 「请输入 8–72 个字符」「正在加载…」「暂无数据」 |

判断口诀：**这句话删掉，用户会不会做错操作？** 会 → 留；不会 → 删。规则类内容属于帮助文档，不属于每次操作的界面。

## 二、现状盘点

| 载体 | 数量 | 说明 |
| --- | --- | --- |
| 页头副标题（`PageHeader` description） | 8 处 | 每个业务页面一行，几乎全是 T1 |
| 卡片头 hint（`.bk-card-head .hint`） | 9 处 | 统计 / 工作台为主，几乎全是 T2 |
| 字段 help（`.bk-field .help`） | 11 处 | 集中在系统设置，T3 为主 |
| 段落声明（`binding-note` / 说明块） | 9 处 | 长句，T1 + T4 |
| KPI 卡口径（`delta` 字段） | 4 处 | T2 |
| 长 placeholder | 3 处 | T3 / 教学式 |
| **合计需处理** | **约 44 条** | 分布 11 个文件，系统设置页占 13 条最密 |

## 三、三档方案（需拍板）

| 档位 | 处理范围 | 条数 | 效果 | 代价 |
| --- | --- | --- | --- | --- |
| **A 全清（推荐）** | T1+T2+T3+T4 全删，页头副标题全部取消 | 44 | 页面只剩标题、数据、操作、状态。干净、可扫描，像内部工具 | 规则说明需转移到帮助文档 |
| B 半清 | 删 T2+T3+T4，保留涉及「撤回 / 有效性 / 权限边界」的合规句 | 26 | 保留安全声明，去掉口径与实现说明 | 合规句仍偏长 |
| C 保守 | 只删 T3（实现暴露） | 8 | 去掉最刺眼的机制说明 | 规则搬运仍在，AI 味只去一半 |

推荐 A。理由：这是内部 B 端系统，规则约束已经由校验、按钮禁用、状态徽标在行为层兑现；把规则写在界面上既不改变行为，又制造阅读噪音。

## 五、不删的部分（明确边界）

- **表单校验与字数限制**：`请输入 8–72 个字符` 等，42 条，全部保留。
- **状态与失败反馈**：`正在加载…`、`该周期没有提问记录`、文件解析失败原因等，保留。
- **无障碍标签**：全部 `aria-label` / `role="status"`，一字不动。
- **权限矩阵行文案**：`搜索 / 问答已发布且有权限的空间` 等 10 条是矩阵内容本身，不是提示，保留。
- **回答模板默认正文**：`TemplateBodyEditor` 内的系统规则区块是功能内容，保留。
- **登录页品牌区**：四条产品特性 + 副标题是上一轮按要求做的品牌侧板，且原型自带，默认保留（如需一并删，请在拍板时说明）。
- **开发态提示**：`DEV_HEADER_AUTH` 相关，仅本地构建可见，保留。

## 六、执行方式

1. `layouts/PageHeader.vue`：`description` 改为可选 prop，父组件不传即不渲染副标题（1 处改动，8 处调用去掉参数与文案）。
2. 按上表逐页删除节点与常量；删掉的 help 若含必需信息（限值、必填），并入 placeholder 或校验提示，不丢失可操作性。
3. 全局搜索「·」「；」在模板文本中的残留，确认无同类遗漏。
4. 验证：
   - `npm run lint` + `npm run typecheck` 通过；
   - `npm run dev` 起服务，逐页截图对比（工作台、知识库、导入、发布、统计、设置、助手、模板、文档详情）；
   - 检查 4 个图表卡删除 hint 后卡片头不塌、右侧动作仍对齐；
   - 实测一次表单提交，确认校验提示未受影响。

## 七、需要拍板的三件事

1. **力度**：A 全清（44 条）/ B 半清（26 条）/ C 保守（8 条）？推荐 A。

3. **登录页品牌区**：四条卖点算不算「AI 味」？删除会让登录页左半屏只剩标题。
