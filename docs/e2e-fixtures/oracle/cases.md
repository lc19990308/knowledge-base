**版本术语**　v2.1 等为文档标示的业务版本。API 里的 `documentVersionId` / `versionNumber` 由系统产生，应从本次导入响应记录映射，不能把 `2.1` 当成 API 版本号。

**适用性**　题卡是拟验收预期。人工语义题的召回、引用及措辞待真实运行校验。当前同名冲突规则不等同于两份不同名称的正文发生冲突，KB04 不预设返回 `CONFLICT`。
