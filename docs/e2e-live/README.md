| P0-02 导入与草稿 | 通过 | 维护者经页面上传，API 读回 `READY`，草稿中的版本 ID 与批次结果一致。 |
| P0-03 审核与生效 | 通过 | 发布前读者搜索为 404。审核人打开申请，通过后读回 `PUBLISHED`，冻结清单中的文档版本与上传一致。 |
| P0-04 搜索与预览 | 通过 | 名称与正文 API 命中同一版本。工作台打开原文看到「费用分摊方式」。无匹配返回 `NO_MATCH`。 |
| P0-05 问答与引用 | 通过 | 报销答复及引用原文包含 15 个工作日。浏览器下载文件的 SHA-256 与上传原件一致。 |
| P0-06 无依据与访问隔离 | 通过 | 授权读者获得专项津贴证据，另一读者未获该受限原文。受限引用和下载接口返回 404。无依据题返回 `NO_EVIDENCE` 且零引用。 |
| P0-07 撤权与撤回 | 通过 | 历史依赖段被屏蔽，旧引用与下载返回 404。撤回后的当前搜索返回 404。专项空间并发撤回结果为 200 和 409，发布指针仅清除一次。 |
| P1-01 文件与审核异常 | 部分通过 | 5 份有正文的多格式原件为 `READY`。扫描件为 `NO_TEXT`，可按名称找到，图片内编号无正文命中。错后缀为 `REJECTED/SUSPICIOUS_FILE`，同名为 `SKIPPED_DUPLICATE`。截断 PDF 为 `FAILED/PROCESSING_FAILED`，页面接受重试且版本 ID 保持一致，原件仍坏则再次失败。已验证驳回后用 API 重提、新申请发布。等待索引时读者搜索为 404，从等待索引标签重新打开可驳回。暂未观察到同一待索引申请随后自动转为已发布。 |

## 实测差异与范围

- 新旧政策混合回答经截图确认，正文写现行 15 个工作日、归档 10 个工作日，API 整段 `kind` 为 `EXPIRED`，页面整段显示「政策已失效」。见[截图](mixed-policy.png)和[题卡回执](policy.jsonl)。
- 原计划对草稿旧 ETag 写成 412，本轮三次收到 409 `ETAG_MISMATCH`。当前草稿实现将版本冲突返回 409。缺 CSRF 返回 403，发布申请同幂等键重放得到同一个申请 ID。
- 新增模型以停用配置验证保存和选项过滤。现有网关的正常问答已实跑。全局模型切换、限流压测以及正式语料准确率未在本轮验证。
