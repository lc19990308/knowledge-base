[浏览器运行证据](ai-qa-e2e-chromium-2026-11-23.jsonl)记录了资源 ID、实际状态和原件哈希。核心流程在修正页面定位和引用断言后完成两轮，每轮使用新资源，第二轮补验了登出。差旅答案可能带多个同名文档片段，按文档版本与原文匹配支持结论的引用，避免依赖引用顺序。

本轮上传了现行报销、住宿表和限制空间样本。旧版、待核实、住宿金额问答、多格式业务原件、真实模型质量、统计 UI 和管理配置 UI 仍待浏览器验收。测试脚本以临时本地 Playwright 驱动执行，正式测试入口和 CI 待接入。
