# 变更记录：问答统计页信息架构重排（2026-11-26）

## 背景

用户反馈：提问明细不该默认折叠收起；统计页信息太多、图表"铺大饼"，希望一屏放下且清晰。方案见 [布局方案](./ai-qa-statistics-layout-plan.md)（已按方案 A 实施，明细 6 行滚动、排行/空间 Top 5）。

改造前 1440×900 实测：页面高 **1920px**，需要滚动；明细折叠后还需再展开。

## 实现过程

仅改 `frontend/src/views/StatisticsView.vue`（外加 `eslint.config.mjs` 的 e2e 全局声明，见文末）。

1. **KPI 四卡 → 一条指标带**：去掉四张独立卡片，改为一条带 1px 分隔线的指标条，每项「标签 + 数值 + 副文本」，副文本承载失败率与未上报次数；高度 118 → 72。
2. **趋势与状态合并为一张卡**：
   - 左 2/3 保留折线图（提问 + 失败虚线），高度 220 → 135；
   - 右 1/3 把环形图换成**堆叠进度条**（已回答 / 生成中 / 处理失败），按最近 200 条明细计数，颜色沿用 `--color-success/warning/danger`；
   - 删除明细区内的时间分布柱状图与状态环形图（与上方趋势、本状态条重复）。
3. **排行 + 空间指标合卡**：两列并排，各显示 **Top 5**（后端已按提问/引用降序返回，直接截取），超出部分在标题右侧提示「另有 N 位 / N 个」；表尾保留「全员合计 / 全部空间」汇总行，合计仍按全量累加，避免只合计 Top 5 造成误读。高度 442 → 148。
4. **明细去折叠、平铺**：删除 `<details>` 与两张明细图表；标题右侧显示「最近 N 条 / 共 M 条（北京时间）」（新增 `detailTotal` 保存接口 `total`）；表格 `max-height: 200px`、表头 `position: sticky`，表内滚动查看 200 条；提问行改为单行 + `title` 展示完整 ID，行高约 28px。高度 744 → 245。
5. **高度收紧**：卡片间距 12 → 8px；卡片内边距按区域分别收紧（KPI 4px、结构卡 8px、明细卡 8px）；紧凑表格行内边距 3px。

## 验证命令与结果

- `cd frontend && npm run lint`：通过（0 问题）。
- `cd frontend && npm run typecheck`：通过。
- `cd frontend && npm run build`：构建成功（chunk 体积警告为既有状况）。
- 浏览器实测（Chrome + Playwright）：
  - 1440×900 浅色/深色：`document.documentElement.scrollHeight = 900`，页面无纵向滚动；深浅主题下趋势线、状态条、吸顶表头颜色均随 token 变化，控制台无报错。
  - 200 条明细：6 行可见，表内滚动到第 200 条正常，表头吸顶（截图 `statistics-after-relayout-scrolled-2026-11-26.png`）。
  - 真实空数据（普通用户本周 0 条）：KPI 显示 0，趋势显示「该周期没有可展示的趋势数据」，状态、排行、空间、明细各自给出空状态文案。
  - 390×844：KPI 2×2、其余单列，`statistics.scrollWidth = 358`（等于容器宽），无本页横向溢出。
- 截图：`docs/e2e-results/statistics-after-relayout-2026-11-26.png`、`-dark-`、`-mobile-`、`-scrolled-`。

## 附带改动：e2e 脚本的 lint 全局

其他会话在 `frontend/e2e/` 留下的临时探测脚本（`sidebar-*.mjs` 等）触发 `document`/`console`/`performance` 未定义，反复卡住全量 lint。在 `frontend/eslint.config.mjs` 中为 `e2e/**/*.mjs` 声明这些浏览器只读全局（只放行运行时全局，`no-undef` 仍能发现拼写错误的变量），并保留 `**/tmp-*.mjs` 忽略。本次未改动这些脚本文件本身。

## 遗留问题

- 明细表固定 200px 高（约 6 行），更长的对账需表内滚动；未做"全屏明细"或导出。
- 排行与空间只展示 Top 5，全量需依赖接口或后续加"查看全部"。
- 390px 下全站顶栏搜索按钮仍有 16px 溢出（`AppLayout` 既有问题，所有页面共存），未改。
